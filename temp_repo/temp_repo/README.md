# Nexus Parallel AI Universe Reality Engine

## Overview

The **Nexus Parallel AI Universe Reality Engine** is a full‑stack platform consisting of a **Node.js/Express** backend and a **React** frontend built with **Vite**. It provides modular AI‑driven services (e.g., report generation) that can be consumed by UI components or other micro‑services.

### Backend (backend-node)

#### Overview

The backend offers reusable services, routes, and controllers. Key features include:
- Report generation service (`src/services/reportGenerator.js`).
- Modular architecture for adding new services under `src/services/`.
- REST API endpoints defined in `src/routes/`.


### Frontend (frontend)

#### Overview

The frontend provides a modern, responsive UI built with **React** (functional components & hooks) and bundled with **Vite**. It consumes the backend APIs to display reports, dashboards, and control panels.

#### Installation & Development (frontend)

```bash
cd frontend
npm install   # or `yarn install`
npm run dev    # Starts Vite dev server at http://localhost:5173
```

The dev server proxies API requests to the backend (see `vite.config.js`). Adjust `.env` to set `VITE_API_BASE_URL` as needed.

#### Building for Production

```bash
npm run build   # Outputs optimized assets to `dist/`
```

Deploy the `dist/` folder to any static hosting service (e.g., Netlify, Vercel, Nginx).
